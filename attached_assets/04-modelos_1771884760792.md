# Módulo 4 — Modelos

Baseado em: [Models | Cursor Docs](https://cursor.com/docs/models)

---

## Visão geral

O Cursor suporta **modelos de ponta** de todos os principais provedores para codificação.

Exemplos (consulte a [página de modelos](https://cursor.com/docs/models) para a lista atual):

- **Claude 4.6** (Opus, Sonnet)  
- **Composer 1.5**  
- **Gemini 3** (Flash, Pro)  
- **GPT-5.2**, **GPT-5.3 Codex**  
- **Grok Code**  

Cada modelo tem **contexto padrão** (ex.: ~200k tokens) e, quando disponível, **modo máximo** (ex.: 1M tokens). As capacidades e preços variam por modelo.

---

## Preços dos modelos

Os [planos do Cursor](https://cursor.com/docs/account/pricing) incluem uso cobrado pelas taxas da API de cada modelo. Por exemplo, os $20 de uso incluídos no plano Pro são consumidos conforme o modelo escolhido e seu preço.

Os limites de uso aparecem no editor. Os preços são por milhão de tokens (input, cache write, cache read, output). Consulte a tabela na documentação e as páginas oficiais de preços:

- [xAI Pricing](https://docs.x.ai/docs/models)  
- [Google Gemini Pricing](https://ai.google.dev/gemini-api/docs/pricing)  
- [Anthropic Pricing](https://www.anthropic.com/pricing#api)  
- [OpenAI Pricing](https://openai.com/api/pricing/)

## Modo Auto

Com **Auto** ativado, o Cursor escolhe o modelo mais adequado à tarefa e com maior confiabilidade conforme a demanda.

- Pode detectar degradação de qualidade e trocar de modelo automaticamente.  
- O consumo segue as taxas da API; no dashboard e no editor você acompanha o uso (incluindo Auto).  
- Se preferir, desative Auto e escolha um modelo fixo; o uso será cobrado pelo preço desse modelo.

---

## Janela de contexto (Context window)

A **context window** é o número máximo de tokens (texto e código) que o modelo considera de uma vez — prompt + resposta.

Cada chat no Cursor tem sua própria janela de contexto. Quanto mais prompts, arquivos anexados e respostas, mais o contexto é preenchido.

Mais detalhes: [working with context](https://cursor.com/learn/context).

---

## Max Mode

O **Max Mode** estende a janela de contexto até o máximo suportado pelo modelo. Mais contexto costuma melhorar resultados em arquivos grandes e projetos complexos.

- Disponível em todos os modelos; mais impacto nos que têm contexto maior que o padrão (~200k).  
- Preço: tarifa da API do modelo + 20% de acréscimo.  
- Detalhes no [módulo Max Mode](06-max-mode.md) e em [Max Mode na documentação](https://cursor.com/docs/context/max-mode).
