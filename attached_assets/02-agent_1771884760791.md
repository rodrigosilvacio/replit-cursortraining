# Módulo 2 — Cursor Agent

Baseado em: [Agent Overview | Cursor Docs](https://cursor.com/docs/agent/overview)

---

## O que é o Agent

O **Agent** é o assistente do Cursor que executa tarefas de código de forma autônoma: edita arquivos, roda comandos no terminal e busca no codebase. Acesso pelo painel lateral com **Cmd+I** (Mac) ou **Ctrl+I** (Windows/Linux).

Saiba mais sobre [como os agents funcionam](https://cursor.com/learn/agents).

---

## Como o Agent funciona

O agent é baseado em três componentes:

1. **Mensagens do usuário** — seus prompts e follow-ups que direcionam o trabalho  
2. **Ferramentas (Tools)** — edição de arquivos, busca no codebase, terminal e outras  
3. **Instruções** — system prompt e [regras](https://cursor.com/docs/context/rules) que guiam o comportamento  

O Agent do Cursor orquestra isso para cada modelo suportado, ajustando instruções e ferramentas por modelo. Você foca em construir; o Cursor cuida das otimizações específicas de cada modelo.

---

## Ferramentas (Tools)

As ferramentas são os blocos de construção do Agent. Elas servem para:

| Ferramenta | Função |
|------------|--------|
| **Semantic search** | Busca por significado no codebase |
| **Search files and folders** | Busca por arquivos e pastas |
| **Web** | Busca na web |
| **Fetch Rules** | Carrega regras do projeto |
| **Read files** | Lê arquivos |
| **Edit files** | Edita arquivos |
| **Run shell commands** | Executa comandos no terminal |
| **Browser** | Navegação em browser |
| **Image generation** | Geração de imagens |
| **Ask questions** | Faz perguntas ao usuário |

Não há limite no número de chamadas de ferramentas que o Agent pode fazer em uma tarefa. Para detalhes: [tool calling fundamentals](https://cursor.com/learn/tool-calling).

## Resumo de mensagens

Quando a conversa fica longa, o Cursor resume e gerencia o contexto automaticamente para manter o chat eficiente.

### Comando /summarize

Use o comando **/summarize** no chat para disparar o resumo manualmente e liberar contexto quando a conversa estiver muito longa.

Mais em: [Context](https://cursor.com/learn/context).

---

## Checkpoints

**Checkpoints** são snapshots automáticos das alterações do Agent no codebase, permitindo desfazer mudanças se necessário.

- Restaure pelo botão **"Restore Checkpoint"** em uma requisição anterior, ou pelo **+** ao passar o mouse sobre uma mensagem.  
- Checkpoints são locais e separados do Git. Use-os para desfazer alterações do Agent; use Git para controle de versão permanente.

---

## Exportar e compartilhar

- **Exportar:** menu de contexto → "Export Chat" para exportar o chat em markdown.  
- **Compartilhar:** envie como link somente leitura; quem recebe pode visualizar e fazer fork da conversa no próprio Cursor.  
- Compartilhamento exige plano pago. Segredos comuns são ofuscados; em Privacy Mode o compartilhamento fica desativado.

## Mensagens na fila (Queued messages)

Você pode enfileirar mensagens de follow-up enquanto o Agent está trabalhando. As instruções entram na fila e são executadas automaticamente quando chega a vez.

### Como usar a fila

1. O Agent processa as mensagens em sequência após terminar a atual.  
2. Arraste para reordenar as mensagens na fila.  
3. As mensagens aparecem em ordem abaixo da tarefa ativa.  
4. Pressione **Enter** para adicionar à fila.  
5. Enquanto o Agent trabalha, digite a próxima instrução.

### Atalhos com o Agent trabalhando

| Ação | Atalho |
|------|--------|
| Enviar imediatamente (furar a fila) | **Cmd+Enter** (Mac) / **Ctrl+Enter** (Windows) |
| Enfileirar mensagem | **Enter** (espera o Agent terminar a tarefa atual) |

### Mensagem imediata

Com **Cmd+Enter** / **Ctrl+Enter**, a mensagem é anexada à última mensagem do usuário e processada na hora, sem esperar na fila.

- Use quando precisar interromper ou redirecionar o trabalho atual.  
- A mensagem é anexada aos resultados das ferramentas e enviada imediatamente.
