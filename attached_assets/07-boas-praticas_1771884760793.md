# Módulo 7 — Boas práticas

Síntese das recomendações da [documentação do Cursor](https://cursor.com/docs), em especial o [Quickstart](https://cursor.com/docs/get-started/quickstart) e [Agent Overview](https://cursor.com/docs/agent/overview).

---

## 1. Planejar antes de codar

Use **Modo Plano** (Shift+Tab no Agent ou `/plan`) para:

- Obter um plano de implementação antes do código  
- Aprovar ou ajustar o plano  
- Deixar o Agent pesquisar o codebase e fazer perguntas de clarificação  

Salve planos em `.cursor/plans/` para documentação e contexto futuro.

---

## 2. Prompts específicos

- Seja **explícito**: o quê, onde e qual resultado esperado.  
- **Referencie padrões** existentes no projeto (pastas, arquivos, convenções).  
- Evite prompts vagos como "corrigir o bug" ou "adicionar testes"; descreva o cenário e o critério de sucesso.

---

## 3. Contexto: @ só quando necessário

- Se você **sabe o arquivo/pasta**, use `@` para mencionar.  
- Se **não sabe**, descreva o que precisa e deixe o Agent buscar (semantic search).  
- **Evite** anexar muitos arquivos irrelevantes; isso pode confundir o Agent.

---

## 4. Quando começar nova conversa

**Nova conversa** quando:

- Uma unidade lógica de trabalho terminou  
- O Agent está confuso ou repetindo erros  
- Você mudou de tarefa ou feature  

**Continuar a mesma** quando:

- Está depurando algo que o Agent acabou de fazer  
- O Agent precisa do contexto das mensagens anteriores  
- Está iterando na mesma feature  

Use **@Past Chats** para referenciar trabalho anterior em vez de colar conversas longas.

---

## 5. Revisar e iterar

- Acompanhe as mudanças na **visão de diff**.  
- Use **Escape** para interromper se o Agent estiver indo na direção errada.  
- Após o Agent terminar: **Review → Find Issues** para uma passada de revisão.  
- **Leia os diffs**: código gerado por IA pode parecer certo e ter erros sutis.

---

## 6. Metas verificáveis

- **Linters** para estilo e qualidade.  
- **Testes** para o Agent rodar e iterar até passar.  
- **Linguagens tipadas** para feedback imediato do type checker.  

**Fluxo TDD sugerido:** peça testes primeiro → confirme que falham → peça a implementação que os faça passar.

---

## 7. Regras (Rules)

- **Regras focadas e acionáveis**; referencie arquivos em vez de copiar código.  
- Adicione regras quando o Agent **repetir o mesmo tipo de erro**.  
- Versionar em Git para o time; atualize a regra quando encontrar um novo padrão de erro.

---

## 8. Filas e interrupção

- **Enter** → enfileira a mensagem (executada após a tarefa atual).  
- **Ctrl+Enter / Cmd+Enter** → envia na hora (interrompe/redireciona).  
- Use a fila para encadear tarefas; use envio imediato para correções urgentes.

---

## Resumo

| Prática | Ação |
|---------|------|
| Planejar | Shift+Tab ou `/plan` antes de implementar |
| Prompts | Específicos, com padrões e resultado esperado |
| Contexto | @ só quando souber o arquivo; senão, descreva e deixe o Agent buscar |
| Conversa longa | Nova conversa por tarefa lógica; @Past Chats para referência |
| Revisão | Diff + Review → Find Issues |
| Qualidade | Linters, testes, tipos; TDD quando fizer sentido |
| Regras | Focadas, versionadas, atualizadas quando o Agent errar |
