## Slash commands (comandos de barra)

**Onde usar:** no **chat do Agent** — abra com **Ctrl+I**, depois digite `/` e o nome do comando na caixa de mensagem (onde você escreve para a IA).

**Onde NÃO usar:** na **Command Palette** (Ctrl+Shift+P). Essa caixa é para comandos do editor (abrir arquivo, salvar, etc.). Se você digitar `plan` ou `/plan` ali, o Cursor não vai executar o slash command e pode criar ou renomear arquivos por engano.

Use esses comandos no chat/Agent (digite `/` e o nome do comando):

| Comando | Descrição |
|---------|-----------|
| `/plan` | Entrar no Modo Plano (planejar antes de codar) |
| `/ask` | Modo Ask — apenas leitura/exploração |
| `/model [nome]` | Definir ou listar modelos |
| `/auto-run [state]` | Ligar/desligar auto-run (ou usar [on\|off\|status]) |
| `/sandbox` | Configurar sandbox e acesso à rede |
| `/max-mode [on\|off]` | Ligar/desligar Max Mode |
| `/new-chat` | Iniciar nova sessão de chat |
| `/vim` | Alternar teclas no estilo Vim |
| `/help [command]` | Ajuda (ex.: `/help plan`) |
| `/feedback` | Enviar feedback para o time |
| `/resume` | Retomar um chat anterior (por nome da pasta) |
| `/usage` | Ver uso e estatísticas |
| `/about` | Informações do ambiente e CLI |
| `/copy-request-id` | Copiar ID da última requisição |
| `/copy-conversation-id` | Copiar ID da conversa |
| `/logout` | Sair da conta |
| `/quit` | Sair do Cursor |
| `/setup-terminal` | Configurar keybindings do terminal |
| `/mcp list` | Listar e configurar servidores MCP |
| `/mcp enable <server>` | Habilitar um servidor MCP |
| `/mcp disable <server>` | Desabilitar um servidor MCP |
| `/rules` | Criar ou editar regras |
| `/commands` | Criar ou editar comandos |
| `/compress` | Resumir a conversa para liberar contexto |
| `/summarize` | Resumir a conversa (gerenciar contexto) |

Referência: [Slash commands](https://cursor.com/docs/cli/reference/slash-commands).

## Atalhos principais

### Agent / Chat

| Ação | Windows/Linux | Mac |
|------|----------------|-----|
| Abrir Agent | **Ctrl+I** | **Cmd+I** |
| Modo Plano (na entrada do Agent) | **Shift+Tab** | **Shift+Tab** |
| Enfileirar mensagem | **Enter** | **Enter** |
| Enviar imediatamente (furar fila) | **Ctrl+Enter** | **Cmd+Enter** |
| Interromper o Agent | **Escape** | **Escape** |

### Inline Edit (edição no editor)

| Ação | Windows/Linux | Mac |
|------|----------------|-----|
| Edição inline com IA | **Ctrl+K** | **Cmd+K** |

### Navegação e geral

| Ação | Windows/Linux | Mac |
|------|----------------|-----|
| Command Palette | **Ctrl+Shift+P** | **Cmd+Shift+P** |
| Novo arquivo | **Ctrl+N** | **Cmd+N** |
| Abrir arquivo | **Ctrl+O** | **Cmd+O** |
| Salvar | **Ctrl+S** | **Cmd+S** |

*(O Cursor herda a maioria dos atalhos do VS Code; ajustes podem existir nas configurações.)*

## Mencionar contexto no chat (@)

Use **@** para incluir contexto no prompt:

| Menção | Uso |
|--------|-----|
| `@arquivo` | Incluir um arquivo |
| `@pasta` | Incluir uma pasta |
| `@Past Chats` | Referenciar conversas anteriores |
| `@regra` | Aplicar regra manual (Apply Manually) |
| `@Codebase` | Deixar o Agent buscar no codebase |
