# Módulo 1 — Início rápido

Baseado em: [Quickstart | Cursor Docs](https://cursor.com/docs/get-started/quickstart)

---

## Objetivo

Ao final deste módulo você saberá: planejar com o Agent, gerenciar contexto, e iterar no código com IA.

[Baixar o Cursor](https://cursor.com/downloads)

---

## 1. Começar com o Agent

Abra o painel do **Agent** com **Cmd+I** (Mac) ou **Ctrl+I** (Windows/Linux).

O Agent executa tarefas de código de forma autônoma: busca no codebase, edita arquivos e roda comandos no terminal.

### Experimente

Pergunte: **"Como este projeto funciona?"**

- [Testar no Cursor](cursor://anysphere.cursor-deeplink/prompt?text=How%20does%20this%20project%20work%3F)

O Agent explora o codebase, lê arquivos relevantes e explica a arquitetura — uma das formas mais rápidas de entender um código novo.

---

## 2. Planejar antes de codar

Uma das mudanças mais impactantes é **planejar antes de codar**.

Pressione **Shift+Tab** na entrada do Agent para ativar o **Modo Plano**. Em vez de começar a escrever código, o Agent vai:

1. Esperar sua aprovação antes de implementar  
2. Criar um plano de implementação detalhado  
3. Fazer perguntas para clarificar requisitos  
4. Pesquisar o codebase para achar arquivos relevantes  

Use **"Save to workspace"** para salvar planos em `.cursor/plans/`. Isso gera documentação para o time e contexto para trabalho futuro.

**Prática:** Peça ao Agent para "adicionar uma nova feature" no Modo Plano. Revise o plano, ajuste se precisar e depois clique para construir.

---

## 3. Deixar o Agent achar o contexto

Não é necessário marcar manualmente cada arquivo no prompt.

O Agent tem busca semântica e puxa contexto sob demanda. Se você perguntar sobre "o fluxo de autenticação", ele encontra os arquivos certos mesmo sem você citar nomes exatos.

- **Regra simples:** se você sabe o arquivo exato, use `@` para mencioná-lo. Se não souber, deixe o Agent encontrar. Incluir arquivos irrelevantes pode confundir o Agent.

---

## 4. Escrever prompts específicos

A taxa de sucesso do Agent melhora muito com instruções específicas.

| Vago | Específico |
|------|------------|
| "adicionar testes para auth.ts" | "Escreva um caso de teste para auth.ts cobrindo o edge case de logout, usando os padrões em `__tests__/` e evitando mocks" |
| "corrigir o bug" | "O formulário de login envia duas vezes ao clicar no botão. Encontre a causa e corrija" |

Seja explícito, cite padrões existentes e descreva o resultado esperado.

---

## 5. Saber quando começar de novo

Conversas muito longas podem fazer o Agent perder foco. **Comece uma nova conversa quando:**

- Terminou uma unidade lógica de trabalho  
- O Agent parece confuso ou repete os mesmos erros  
- Você está mudando de tarefa ou feature  

**Continue a conversa quando:**

- Está depurando algo que ele acabou de construir  
- O Agent precisa de contexto de mensagens anteriores  
- Está iterando na mesma feature  

Use **@Past Chats** para referenciar conversas antigas em novas sessões em vez de colar discussões inteiras.

---

## 6. Revisar e iterar

Acompanhe o trabalho do Agent. A **visão de diff** mostra as mudanças em tempo real. Se ele estiver indo na direção errada, pressione **Escape** para interromper e redirecionar.

Depois que o Agent terminar, use **Review → Find Issues** para uma passada de revisão que analisa as edições e aponta possíveis problemas.

Código gerado por IA pode parecer correto e ter erros sutis. Leia os diffs com atenção. Quanto mais rápido o agent trabalha, mais importante é o seu processo de revisão.

---

## 7. Dar metas verificáveis

Agents performam melhor com alvos claros:

- Configure linters para pegar estilo e qualidade automaticamente  
- Escreva testes para o Agent rodar e iterar até passar  
- Use linguagens tipadas para feedback imediato do type checker  

**Fluxo sugerido:** peça ao Agent para escrever os testes primeiro, confirme que falham, depois peça a implementação que faça os testes passarem.
